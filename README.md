## 🎯 الميزات الأساسية (الاستخدام اليومي)

### 1️⃣ **تسجيل الحضور** ⚡ (أهم ميزة)
```
✅ ضغطة واحدة لكل طالب = حاضر
❌ اضغط مرة أخرى = غائب
⚠️  اختر معذرة من القائمة = معذور

⏱️ مدة التسجيل: أقل من دقيقة للفصل كامل
📊 تقرير فوري قابل للطباعة والإرسال
📱 رسالة تلقائية لولي الطالب (الغايب)
```

### 2️⃣ **إدارة الدرجات** (دقيقة وتلقائية)
```
📝 حساب تلقائي حسب معايير الوزارة:
   - 20% نشاط يومي
   - 30% اختبارات قصيرة
   - 50% امتحان نهائي

🎯 تنبيهات فورية:
   ⭐⭐⭐⭐⭐ ممتاز (90+) 🎉
   ⭐⭐⭐⭐ جيد جداً (80-89)
   ⭐⭐⭐ جيد (70-79)
   ⭐⭐ مقبول (60-69)
   ⭐ يحتاج دعم (<60) 🆘
```

## 🚀 كيفية الاستخدام (ببساطة شديدة)

### صباح اليوم:
1. افتح التطبيق
2. اضغط "تسجيل الحضور"
3. اضغط على اسم كل طالب (✅ للحضور، ❌ للغياب)
4. للمعاذير: اختر السبب من القائمة
5. اضغط "حفظ وطباعة" → جاهز! 📋

### عند إدخال درجات:
1. اضغط "إدخال الدرجات"
2. اختر نوع الدرجة (نشاط / اختبار / نهائي)
3. أدخل درجة كل طالب
4. التطبيق يحسب تلقائياً الدرجة النهائية
5. يعطيك تنبيهات للضعفاء 🎯

### عند نهاية الفترة/الفصل:
1. اضغط "طباعة" على التقرير
2. طبعه أو احفظه كـ PDF
3. ارسله للإدارة 📧
